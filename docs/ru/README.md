# Настройка клиента

**Русский** | [English](../README.md)

Установка сервера, добавление/удаление клиентов и QR-коды: [server.md](server.md).

На компьютерах используется официальный бинарник **xray-core** без GUI (не v2fly `v2ray`:
в нём нет поддержки REALITY/Vision) с клиентским конфигом, сгенерированным на сервере.
На телефонах используется GUI-приложение, которое импортирует ссылку для импорта (share link)
и пропускает через туннель весь трафик устройства.

| ОС | Инструкция | Что использует |
|---|---|---|
| Windows | [client-windows.md](client-windows.md) | `<email>.config.json`, без GUI |
| Linux | [client-linux.md](client-linux.md) | `<email>.config.json`, без GUI |
| macOS | [client-macos.md](client-macos.md) | `<email>.config.json`, без GUI |
| Android | [client-android.md](client-android.md) | `<email>.link.txt`, v2rayNG |
| iOS / iPadOS | [client-ios.md](client-ios.md) | `<email>.link.txt`, Streisand / V2Box / Shadowrocket |
| Только браузеры | [client-browsers.md](client-browsers.md) | Firefox, Chromium (Chrome/Edge/Brave…), Safari, поверх клиента для компьютера |

Разделы 2–3 ниже относятся к настройке на компьютере (без GUI).

## 1. Получите клиентский конфиг

У каждого клиента свои файлы, их создаёт `install.sh` (первый клиент) или `add_user.sh`:

- `clients/<email>.config.json`: конфиг xray-core, используется в инструкциях ниже.
- `clients/<email>.link.txt`: ссылка для импорта (share link) `vless://` для GUI-приложений
  (v2rayN, v2rayNG, Streisand, Hiddify…), если вы предпочитаете GUI.

Скопируйте их с сервера, выполнив на своём компьютере (Windows Terminal,
macOS или Linux; OpenSSH `scp` встроен):

```
scp "<host>:/opt/xray-stack/clients/<email>.*" .
```

Или выведите файл на сервере (`sudo cat clients/<email>.config.json`) и вставьте
содержимое в файл. Подробнее в [server.md](server.md#как-перенести-файлы-клиента-на-компьютер).

Обращайтесь с обоими файлами как с паролем: любой, у кого они есть, может пользоваться
прокси, пока клиент не удалён через `remove_user.sh`. Используйте отдельного клиента для каждого устройства.

## 2. Что даёт клиент

Конфиг открывает два локальных прокси, доступных только на `127.0.0.1`:

| Порт | Протокол | Для чего |
|---|---|---|
| `10808` | SOCKS5 (TCP + UDP) | приложения с поддержкой SOCKS, `curl -x socks5h://…` |
| `10809` | HTTP/HTTPS | настройки «системного прокси» ОС, переменные окружения `http_proxy` |

Маршрутизация раздельная: домены, перечисленные в конфиге (включая ваш собственный домен), и
адреса локальной сети идут **напрямую**; всё остальное идёт через сервер. Чтобы это изменить, отредактируйте список `routing.rules[0].domain`
(`domain:example.com` соответствует домену и всем его поддоменам).

Автоматически ничего не туннелируется: приложения должны использовать прокси (системный прокси,
настройка в приложении или переменные окружения). Для общесистемного туннеля наподобие VPN используйте
вместо этого GUI-клиент с режимом TUN (v2rayN на Windows, Hiddify и т. п.) и импортируйте ссылку для импорта (share link).

## 3. Проверка (любая ОС)

```
curl -x socks5h://127.0.0.1:10808 https://ifconfig.me      # выводит IP сервера
curl -x http://127.0.0.1:10809 https://ifconfig.me         # то же, через HTTP-прокси
curl https://ifconfig.me                                   # ваш настоящий IP (без прокси)
```

(В Windows используйте `curl.exe`, а не алиас `curl` из PowerShell.)

Если не работает, запустите xray на переднем плане (см. соответствующую инструкцию) и прочитайте лог. Частые причины:
неверные системные часы (REALITY требует расхождения не более ~2 минут), клиент был удалён или
xray на сервере не перезапустили после `add_user.sh`, либо 443/tcp заблокирован в вашей сети.

## Обновление

Скачайте более новый релиз xray-core (или выполните `brew upgrade xray` / повторно запустите
скрипт установки для Linux) и перезапустите клиент. Конфиг не меняется.
