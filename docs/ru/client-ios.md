# Клиент: iOS / iPadOS

**Русский** | [English](../client-ios.md)

На iOS нет варианта без графического интерфейса и нет официального приложения xray-core;
используйте клиент из App Store, который поддерживает **VLESS + REALITY + XTLS-Vision**
и работает как системный VPN.

| Приложение | Цена | Примечания |
|---|---|---|
| **Streisand** | бесплатно | Простое; импорт через QR / буфер обмена; правила маршрутизации. |
| **V2Box** | бесплатно (реклама) | Есть и на macOS. |
| **Hiddify** | бесплатно | Открытый исходный код; есть и на Android/десктопе. |
| **Shadowrocket** | платно | Самые гибкие правила; широко используется. |

Доступность зависит от региона App Store; если какого-то приложения нет, попробуйте
другое из списка. Все они импортируют одну и ту же ссылку `vless://`.

## 1. Создайте клиента для устройства

Один клиент на устройство, чтобы при потере телефона можно было отозвать доступ только
у него. На сервере (`ssh <host>`):

```
cd /opt/xray-stack
sudo bash add_user.sh
```

Ответьте **y** на предложение перезапустить xray, иначе новый клиент будет отклонён.

## 2. Импортируйте ссылку для импорта (share link)

**QR-код (проще всего)**: выведите его в SSH-сессии на сервере:

```
cd /opt/xray-stack
sudo bash show_qr.sh
```

Выберите клиента по номеру (или передайте его email аргументом). `add_user.sh` также
предлагает показать код сразу после создания клиента.

В приложении используйте действие **+** / **Scan QR** (Streisand: **+** → *Scan QR code*;
Shadowrocket: значок сканера вверху слева). Приложение «Камера» в iOS тоже распознаёт
код и предлагает открыть его в установленном клиенте.

**Буфер обмена**: передайте строку `vless://…` из `clients/<email>.link.txt` на
устройство по приватному каналу (AirDrop с Mac, заметка в менеджере паролей; не через
мессенджер, синхронизирующийся с облаком), скопируйте её и откройте приложение;
большинство приложений сами предлагают импорт из буфера обмена, либо используйте
**+** → *Import from clipboard*.

Проверьте импортированный профиль: адрес = ваш домен, порт 443, flow
`xtls-rprx-vision`, security `reality`, SNI = ваш домен, fingerprint `chrome`,
публичный ключ и short ID заполнены.

## 3. Подключение

Выберите профиль и включите подключение. При первом запуске iOS попросит
**добавить конфигурацию VPN**: разрешите (Face ID / код-пароль). В строке состояния
появится значок VPN.

## 4. Раздельная маршрутизация (необязательно)

Ссылка для импорта содержит только настройки сервера. Чтобы направить часть сайтов
напрямую, добавьте правила в приложении (Streisand: *Routing*; Shadowrocket: *Config* →
*Rule*) с действием **DIRECT** для доменов, которые нужно пустить в обход, например
`DOMAIN-SUFFIX,example.com` в Shadowrocket. Чтобы поведение совпадало, используйте те же
домены, что и в `routing.rules[0].domain` вашего десктопного `<email>.config.json`;
локальную сеть оставьте напрямую.

## 5. Чтобы туннель не отключался

- iOS может разрывать туннель при смене сети; в большинстве приложений есть опция
  **On Demand** / *Connect on demand* для автоматического переподключения.
- В Настройки → VPN видно подключение; там же его можно включить или выключить.

## Устранение неполадок

- Проверка подключения не проходит: неверное время на устройстве (REALITY требует
  точного времени), клиент удалён на сервере или xray не перезапущен после `add_user.sh`.
- Работает по Wi-Fi, но не через сотовую сеть (или наоборот): эта сеть блокирует или
  замедляет 443/tcp до сервера; в конфиге исправлять нечего.
