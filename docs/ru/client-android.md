# Клиент: Android

**Русский** | [English](../client-android.md)

На Android нет варианта без графического интерфейса: используйте GUI-приложение, которое
запускает xray-core как VPN-сервис (туннель для всего устройства). Рекомендуется
**v2rayNG** (открытый исходный код, внутри xray-core). Альтернативы с тем же способом
импорта: Hiddify, NekoBox.

## 1. Создайте клиента для телефона

Используйте отдельного клиента для каждого устройства, чтобы при потере телефона
можно было отозвать доступ только у него. На сервере (`ssh <host>`):

```
cd /opt/xray-stack
sudo bash add_user.sh
```

Ответьте **y** на предложение перезапустить xray, иначе новый клиент будет отклонён.

## 2. Установите v2rayNG

- Google Play: найдите «v2rayNG», или
- APK с <https://github.com/2dust/v2rayNG/releases/latest>
  (`v2rayNG_<version>_arm64-v8a.apk` подходит почти для всех современных телефонов).

## 3. Импортируйте ссылку для импорта (share link)

**QR-код (проще всего)**: выведите его в SSH-сессии на сервере:

```
cd /opt/xray-stack
sudo bash show_qr.sh
```

Выберите клиента по номеру (или передайте его email аргументом). `add_user.sh` также
предлагает показать код сразу после создания клиента.

В v2rayNG: **+** (вверху справа) → **Scan QR code**. Сделайте окно терминала
достаточно большим, чтобы код был виден целиком.

**Буфер обмена**: передайте строку `vless://…` из `clients/<email>.link.txt` на телефон
по приватному каналу (не через мессенджер, синхронизирующийся с облаком), скопируйте её,
затем **+** → **Import config from clipboard**.

Проверьте импортированный профиль: адрес = ваш домен, порт 443, flow
`xtls-rprx-vision`, security `reality`, SNI = ваш домен, fingerprint `chrome`,
публичный ключ и short ID заполнены.

## 4. Подключение

Нажмите на профиль, чтобы выбрать его, затем на круглую кнопку **V** внизу. Подтвердите
системный запрос Android на создание VPN. Нажмите «Check connection» (полоса внизу):
должна отобразиться задержка в мс.

## 5. Раздельная маршрутизация (необязательно)

Ссылка для импорта содержит только настройки сервера, но не список доменов для прямого
подключения из десктопного конфига. Чтобы направить часть сайтов напрямую, откройте ☰ →
**Routing settings** → **Direct URL or IP** и добавьте по одному правилу на строку,
например:

```
domain:example.com
geosite:private
geoip:private
```

Чтобы поведение совпадало, используйте те же домены, что и в `routing.rules[0].domain`
вашего десктопного `<email>.config.json`. Установите **Domain strategy** в `AsIs`.

Туннелирование по приложениям: ☰ → **Settings** → **Per-app proxy**, чтобы пускать
в туннель только выбранные приложения (или, наоборот, исключить выбранные).

## 6. Чтобы туннель не отключался

- Настройки Android → **Apps** («Приложения») → v2rayNG → **Battery** («Батарея») →
  **Unrestricted** («Без ограничений»), иначе система может завершить туннель.
- Постоянное подключение (необязательно): Настройки Android → **Network & internet**
  («Сеть и интернет») → VPN → шестерёнка рядом с v2rayNG → **Always-on VPN** (и
  «Block connections without VPN», если нужен kill switch).

## Устранение неполадок

- «Check connection» не проходит: неверное время на телефоне (REALITY требует точного
  времени), клиент удалён на сервере или xray не перезапущен после `add_user.sh`.
- Работает по Wi-Fi, но не через мобильную сеть (или наоборот): эта сеть блокирует или
  замедляет 443/tcp до сервера; в конфиге исправлять нечего.
- Логи: ☰ → **Logcat**.
